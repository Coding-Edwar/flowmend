# Flowmend

A guided web form that helps staff at small nonprofits describe one internal process that isn't working, so they can get practical, budget-aware ideas for fixing it.

## The problem

Most small nonprofits have at least one process that eats staff time: a monthly donor report compiled by hand, volunteer onboarding that lives in someone's inbox, grant reporting that keeps missing deadlines. The people who live with these processes know they're broken, but they rarely have the time or budget to hire a consultant. It's also surprisingly hard to describe a messy process clearly enough for anyone else to help fix it.

Flowmend asks the right questions in the right order, so you end up with a clear, complete picture of the process: what happens, where it breaks, and what "better" would look like.

## Who it's for

- **Primary:** operations, program and admin staff at small nonprofits.
- **Secondary:** consultants and volunteers who support nonprofits and want a consistent way to gather the facts before giving advice.

## What it does today

Flowmend walks you through six short sections:

1. Process overview
2. Current workflow steps
3. Pain points and bottlenecks
4. Inputs, outputs and data
5. What success looks like
6. Constraints and context

A progress bar and per-section counts show how far you've got. When you're done, you can export your answers as a plain-text file to share with a colleague, a consultant or an AI assistant.

Everything stays in your browser, and nothing is sent to a server. Answers aren't saved yet, so refreshing the page clears them.

## Why I'm building this

I'm building Flowmend to grow my software skills, especially TypeScript and Docker, while making something genuinely useful: a practical tool that helps small nonprofits and small businesses fix the processes that slow them down.

The first prototype was built with the help of AI. I'm now rebuilding it by hand, step by step, so that I understand and own every line.

## Run it locally

You need [Node.js](https://nodejs.org/) 24 LTS.

```sh
git clone https://github.com/Coding-Edwar/flowmend.git
cd flowmend
npm ci
npm run dev
```

Then open the local address Vite prints in the terminal (usually http://localhost:5173).
